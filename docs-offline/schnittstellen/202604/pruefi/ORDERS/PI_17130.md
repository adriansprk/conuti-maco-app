Die Statusspalte trägt zwei Vokabulare, weil das Handbuch zwei Fragen beantwortet: an einer **Gruppenzeile** sagt *Muss*, *Soll* oder *Kann*, ob das EDIFACT-Segment vorhanden sein muss; an einer **Feldzeile** sagt *X*, dass dieser Qualifier in diesem Prüfidentifikator benutzt wird.
