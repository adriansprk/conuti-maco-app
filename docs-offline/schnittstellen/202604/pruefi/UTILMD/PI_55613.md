Die Statusspalte trägt zwei Vokabulare, weil das Handbuch zwei Fragen beantwortet: an einer **Gruppenzeile** sagt *Muss*, *Soll* oder *Kann*, ob das EDIFACT-Segment vorhanden sein muss; an einer **Feldzeile** sagt *X*, dass dieser Qualifier in diesem Prüfidentifikator benutzt wird. Die Spalte **Bedingung** nennt die Marken, unter denen das Handbuch eine Zeile an eine Voraussetzung knüpft; ihr Klartext steht unter der Tabelle.
