| Marke | Bedingung |
|---|---|
| **[249]** | Innerhalb eines SG4 IDE müssen alle DE1131 der SG4 STS+E01 (Status der Antwort) den identischen Wert enthalten |
| **[321]** | Wenn im DE3155 in demselben COM der Code EM vorhanden ist |

| **[514]** | Hinweis: Es darf nur eine Information im DE3148 übermittelt werden |
| **[931]** | Format: ZZZ = +00 |
| **[939]** | Format: Die Zeichenkette muss die Zeichen @ und . enthalten |
| **[940]** | Format: Die Zeichenkette muss mit dem Zeichen + beginnen und danach dürfen nur noch Ziffern folgen |

<Hinweisbereich>

Ein **\*** hinter einem Feld- oder Gruppennamen kennzeichnet ein **Pflichtfeld** beziehungsweise eine Pflichtgruppe. Der Typ steht daneben; wo der Wert im EDIFACT-Segment landet, zeigt das Info-Zeichen neben dem Feldnamen.

Die Statusspalte trägt zwei Vokabulare, weil das Handbuch zwei Fragen beantwortet: an einer **Gruppenzeile** sagt *Muss*, *Soll* oder *Kann*, ob das EDIFACT-Segment vorhanden sein muss; an einer **Feldzeile** sagt *X*, dass dieser Qualifier in diesem Prüfidentifikator benutzt wird. Beides bleibt stehen, wie die Quelle es führt.

Das Anwendungshandbuch führt zu diesem Prüfidentifikator **55 Zeilen**. Sie stehen in der Reihenfolge des Handbuchs, eingerückt nach Segmenten: eine Zeile ohne Datenelement eröffnet ein Segment, die Zeilen darunter sind seine Datenelemente.

Die Spalte **Bedingung** nennt die Marken, unter denen das Handbuch eine Zeile an eine Voraussetzung knüpft; ihr Klartext steht unter der Tabelle.

Im Testdatenbestand liegen zu diesem Prüfidentifikator ein Vorgang unter dem Nachrichtentyp `utilmd`. Jeder ist zweimal abgelegt — als EDIFACT-Nachricht und als BO4E-JSON.
